# 小小觉醒 · 绒光冒险

粉彩绘本风格的剧情成长动作游戏。银发主角从归绒学宫的末等生出发，通过职业选择、伙伴觉醒与三场试炼完成逆袭。

## 游玩

当前在线版本：https://little-star-rise-megan.mckenzie-ouyang.chatgpt.site （使用站点所有者的 ChatGPT 账号登录）。

此仓库为完整静态网页，可部署到任意静态主机。若使用 GitHub Pages，在 Settings → Pages 中选择 Deploy from a branch / main / root。仓库内容不会自行启用 Pages。

## 操作

- WASD / 方向键移动；Shift 或 E 疾闪；Q 主动星术；空格觉醒。
- 手机按住场景拖动移动，点击右侧技能按钮。
- 自动攻击，拾取碎片升级，升级三选一。
- 剧情节点自动存档；失败可重试本场。存档保存在当前浏览器。

## 内容

- 织星师、唤灵师、绘梦师三职业。
- 末末的吞噬反击 / 铃灵的共鸣护盾两条伙伴路线。
- 外出试炼、旧梦林地、归院考核，以及改变支援和结局的剧情抉择。
- 远程敌人、冲锋精英、预警攻击和分阶段首领弹幕。

## 美术与实现

`game.js` 为战斗和剧情逻辑，`art.js` 为绘制与特效，`art.css` 为布局和 UI。`assets/` 包含实际使用的透明精灵、纸张刺绣 UI 底图、地面与剧情插画。图片由 Image Generation 生成，运行时通过 Canvas / CSS 呈现。角色使用新分层银发立绘：31 个绘制部件打包为纹理图集，8 个步态关键姿势连续插值，双骨骼腿部、独立靴子、衣摆与手臂摆动、眨眼，以及起步/停步混合。施法有蓄力、抬手、释放与收势，冲刺可以取消施法。普通自动光弹由末末发射。

## 本地运行与检查

```bash
python -m http.server 8000
node tests/smoke.cjs
node tests/rig.cjs
```

在浏览器打开 http://localhost:8000。无构建步骤和第三方运行依赖。
