# 杂役院 · 第一回

粉彩绘本风格的剧情探索与主动动作游戏。主角被划去考核资格，被派去照看一只不肯进食的凶兽，通过院落任务、人物选择和一场亲手赢下的切磋拿回名额。

试玩：https://little-star-rise-megan.mckenzie-ouyang.chatgpt.site （使用站点所有者的 ChatGPT 账号登录）。

## 第一回内容

在院门与秦管事问清缘由，到膳房领取食物、采齐赤叶草，照料兽栏里的阿团。通过主动闪避与近身反击看懂它的节奏，再选择留下伙伴或让旧诊簿作证。事件结束后习得「听息·借势」，向沈砚发起考核切磋，通关后可继续与院中人物对话或重新切磋。

没有自动散射、定时怪潮、被动升级或全屏大招。普通攻击、闪身与借势均由玩家主动操作。敌人使用有预警的扑击、突进和横扫；抓住收招窗口或成功闪避后的破绽使用借势，会获得更强的反击效果。两条剧情选择改变战斗效果和人物回应。

## 操作

- WASD / 方向键移动；也可点击地面或人物附近行走。
- E：靠近后交谈或采集；手机点击「谈 / 采」。
- J：近身三段连击；K：习得后主动借势；空格：闪身。
- Tab：查看手记；Esc：暂停。
- 手机按住场景拖动移动，点击右下角动作按钮。
- 剧情节点保存在当前浏览器。战斗中重载会回到开战前；失败可直接重试。

## 文件与检查

`index.html`、`courtyard.js`、`courtyard.css` 为当前游戏。`hero-rig-data.js` 与 `hero-rig.js` 绘制分层银发角色，包含八个连续插值的步态关键姿势、双骨骼腿部、独立靴子和手臂动作。美术资源位于 `assets/`；新增院落与三位 NPC 为绘本风格栅格插画。

在文件目录启动任意静态服务器即可运行，无构建依赖。执行 `node tests/courtyard.cjs` 检查完整剧情路线、物品交付、主动战斗、闪避反击、失败重试、结局与存档。

此前的 UI 组件预览仍保留在 `ui/`。完整历史可通过 Git 提交查看。
